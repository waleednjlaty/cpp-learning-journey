# C++ and Java Learning Projects

Beginner-to-intermediate exercises collected while learning programming fundamentals.

## Sections

- `CPP/Basics` — small programs, games, recursion, and utilities
- `CPP/OOP` — classes, encapsulation, inheritance, and object-oriented examples
- `CPP/DataStructures` — linked lists, queues, graphs, stacks, and hash tables
- `CPP/CodeForces` — introductory competitive-programming practice
- `JAVA/OOP` — Java object-oriented programming exercises
- `SFML` — a C++ graphics experiment

See the README inside each main folder for more details.
