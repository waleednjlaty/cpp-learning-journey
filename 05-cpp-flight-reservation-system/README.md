# ✈️ نظام واحة وليد لحجز الرحلات | Waleed's Oasis Flight Reservation System

مشروع تعلّمي باستخدام **C++** لمحاكاة حجز رحلات الطيران عبر الطرفية (Console). يطبّق هياكل البيانات والدوال والمصفوفات والاستدعاء الذاتي على مثال عملي. ليس نظام حجز متصلًا بشركة طيران.

## 🚀 ميزات النظام (Features)
- **عرض الرحلات المتاحة:** استعراض تفاصيل الرحلات (رقم الرحلة، الوجهة، سعر المقعد، والمقاعد المتاحة) بجدول منسق بشكل احترافي.
- **حجز الرحلات:** إمكانية تسجيل اسم المسافر، اختيار رقم الرحلة، وتحديد عدد المقاعد مع تحديث فوري للمقاعد المتبقية في الطائرة.
- **إدارة الحجوزات:** استعراض قائمة بجميع الحجوزات الحالية وتفاصيلها.
- **حساب الإحصائيات (متقدم):** حساب إجمالي المبالغ المستحقة وإجمالي عدد المقاعد المحجوزة باستخدام الخوارزميات العودية (Recursion).
- **التحقق من الإدخال:** إعادة طلب الأرقام عند إدخال نص، ورفض المقاعد السالبة أو الصفرية والحجز فوق المتاح، مع حد أقصى 50 حجزًا.

## 🛠️ التقنيات والمفاهيم المستخدمة (Technologies & Concepts)
- **اللغة الأساسية:** C++
- **هياكل البيانات (Structures):** استخدام `struct` لتمثيل بيانات الرحلات (`flight`) وبيانات الحجوزات (`rese`).
- **البرمجة العودية (Recursion):** تطبيق مفهوم الـ Recursion في دمج وحساب الإحصائيات المالية والمقاعد.
- **تنسيق الواجهة:** استخدام مكتبة `<iomanip>` لترتيب الجداول والمحاذاة، ومكتبة `<windows.h>` لإضافة الألوان وتأثيرات الكتابة المتحركة للـ Logo.

## 💻 كيفية التشغيل (How to Run)
المتطلبات: Windows ومترجم C++17 مثل MinGW-w64؛ يستخدم المشروع `windows.h`.

```powershell
git clone https://github.com/waleednjlaty/cpp-learning-journey.git
cd cpp-learning-journey/05-cpp-flight-reservation-system
g++ -std=c++17 -Wall -Wextra -pedantic Waleed_Hotel.cpp -o flight-reservation.exe
.\flight-reservation.exe
```

## الاختبارات

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic tests/reservation_test.cpp -o reservation-test.exe
```

تغطي الاختبارات الحجز الصحيح، إجمالي المبلغ والمقاعد، المقاعد السالبة والصفرية، تجاوز المتاح، رقم رحلة غير موجود، الإدخال النصّي، وحدّ الحجوزات.

## حدود النسخة الحالية

- تُحفظ الحجوزات في الذاكرة فقط وتُفقد عند إغلاق البرنامج.
- البيانات والأسعار تجريبية وثابتة؛ لا توجد حجوزات أو مدفوعات حقيقية.
- الواجهة مخصصة لـWindows ولا تتضمن قاعدة بيانات أو إلغاء حجز.
- التعامل مع انتهاء الإدخال (EOF) يحتاج تحسينًا؛ التشغيل الحالي مخصص للطرفية التفاعلية.

الخطوات التالية المقترحة: الحفظ في ملف، إلغاء الحجز، وفصل منطق الحجز عن الواجهة.
