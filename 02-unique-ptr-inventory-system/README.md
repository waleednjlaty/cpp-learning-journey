# UniquePtr Inventory System

A practical C++ learning project focused on ownership, `std::unique_ptr`, resource lifetime, and organizing a small inventory system.

## Structure

- `src/main.cpp` — program entry point
- `src/functions.hpp` — inventory operations
- `src/Weapons.hpp` — weapon model
- `src/includes.hpp` — shared includes and declarations

The compiled binary is intentionally not stored in the repository.
